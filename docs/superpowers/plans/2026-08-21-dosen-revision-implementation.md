# Dosen Revision APK Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver Android demo APK implementing the lecturer revisions while preserving the existing commuter map layout.

**Architecture:** Keep the current Flutter feature structure and Express/Prisma backend. Add platform resolution and vision as isolated backend services, pass route line IDs into a dedicated map preview, and keep ML Kit/TTS local with Gemini calls proxied through the backend.

**Tech Stack:** Flutter/Dart, GoRouter, CustomPainter, Node.js/Express, TypeScript, Prisma/PostgreSQL Neon, Gemini via `@google/genai`, Android camera, ML Kit, Flutter TTS.
